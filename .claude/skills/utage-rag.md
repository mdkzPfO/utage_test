# UTAGE RAG 検索スキル

## 概要

宴(UTAGE) — Unity用ビジュアルノベルツール「宴」の公式ドキュメント(67ページ、174チャンク)をベクトル検索できるMCPツール。
検索結果には元ページのURLが含まれるため、ユーザーに公式ドキュメントへのリンクを提示できる。

データソース: https://madnesslabo.net/utage/

## MCPツール名

`search_utage_docs`

## いつ使うか

以下のいずれかに該当するとき、このツールを呼び出すこと:

- **宴の機能確認**: 宴で○○はできるか？どう実装するか？
- **コマンド検索**: Selection, Jump, Param, Bg, BgEvent, Shake, Tween, FadeIn/Out, Se, Bgm 等
- **設定シート**: Character, Texture, Sound, Layer, Param, Animation, LipSynch, EyeBlink 等のシート設定方法
- **シナリオ記述**: エクセルでのシナリオ記述方法、シナリオラベル、条件分岐、サブルーチン、マクロ
- **拡張プラグイン**: Live2D, E-mote, Spine, Adx2, Text Animator, Addressable Assets
- **TextMeshPro**: フォントアセット、リッチテキストタグ、マテリアル、スプライト、グラデーション
- **UI・演出**: メッセージウィンドウ、選択肢レイアウト、画面エフェクト、カメラ制御
- **システム**: セーブ/ロード、ギャラリー、バックログ、デバッグメニュー
- **ビルド・配信**: ビルド方法、DLコンテンツ、Addressable、StreamingAssets
- **多言語対応**: ローカライズ設定、言語切替、ボイス言語分離
- **移植**: コンシューマ移植時の制約、Define Symbols
- **既存システムとの統合**: 会話シーンとしての組み込み、UIへのシナリオ埋め込み、SendMessage連携

## パラメータ詳細

### query (必須)
検索クエリ文字列。日本語推奨（ドキュメントが日本語のため）。

**効果的なクエリの書き方:**
- 具体的な機能名を含める: 「Selectionコマンドで条件付き選択肢」
- やりたいことを書く: 「キャラクターの表情をシナリオ中に変える方法」
- コマンド名がわかっている場合はそのまま: 「BgEventコマンドの使い方」

**避けるべきクエリ:**
- 曖昧すぎる: 「宴の使い方」（広すぎて精度が落ちる）
- 英語のみ: 「how to use selection」（日本語の方がヒット率が高い）

### category (任意)
カテゴリで検索範囲を絞り込む。指定しない場合は全カテゴリ横断検索。

| カテゴリ値 | 内容 | 含まれる情報 |
|-----------|------|------------|
| `tutorial` | チュートリアル | プロジェクト作成、セットアップ、基本操作（テキスト、キャラ、背景、サウンド、パラメータ、ジャンプ、選択肢） |
| `reference` | リファレンス | 全体構成、グラフィックオブジェクト比較、設定シート一覧、コマンド一覧（全コマンド網羅）、プログラム構成、Tools>Utageメニュー |
| `manual` | マニュアル | テキスト表示、UI変更、会話シーン統合、UIへの埋め込み、Unity連携、イベント処理、ビルド/DL、全画面テキスト、ローカライズ、デバッグ、コンシューマ移植、サブシナリオ、シナリオ割り込み、TIPS機能、ランタイムシナリオ、Unity公式拡張対応 |
| `extension` | 拡張プラグイン | Text Animator, Addressable Assets, Adx2, Live2D, E-mote, 外部アセット(Spine例) |
| `textmeshpro` | TextMeshPro | 基本、コンポーネント、フォントアセット、マテリアル、リッチテキストタグ一覧、スタイルシート、スプライト、グラデーション、プロジェクト設定、コラム |
| `sample` | サンプル | Unityちゃんチュートリアル、クイズゲーム作成、青空文庫ゲーム化 |
| `unity-general` | Unity一般 | プロジェクト破損原因、UI編集、頂点カスタム、素早い再生モード、複数シーン実装、ADF/インターフェース、UnityのTIPS |
| `case-study` | 事例紹介 | 宴を使った46作品紹介、アセットコンテスト大賞、CEDEC AWARDS優秀賞 |
| `qa-download` | Q&A・DL | FAQ（ライセンス、対応Unity、エラー対処）、Q&Aフォーラム、リリースノート(v4.2.7まで) |

### top_k (任意)
取得件数。デフォルト10、最大20。
- 概要を知りたい → 3〜5で十分
- 網羅的に調べたい → 10〜15
- 特定コマンドの全用法 → 15〜20

## 検索結果の出力形式

各結果には以下が含まれる:
```
--- Result 1 (distance: 0.2713) ---
File: 09_selection.md
Category: tutorial
Section: selection
Source: https://madnesslabo.net/utage/?page_id=641    ← 公式ページへのリンク

（チャンク本文）
```

## 回答時のガイドライン

1. **ソースURLを必ず提示する**: 回答の末尾に「参考: [公式ドキュメント](URL)」としてリンクを付ける
2. **distance値で信頼度を判断する**:
   - 0.3以下 → 高い信頼度。そのまま回答の根拠にできる
   - 0.3〜0.6 → 関連あり。内容を確認して適切な部分を抽出
   - 0.6以上 → 関連性が低い可能性。「ドキュメントに詳細な記載が見つかりませんでした」と伝える
3. **複数結果を統合する**: 同じトピックの異なるチャンクが返ることがある。矛盾がなければ統合して回答
4. **不足を伝える**: 検索結果だけでは回答が不十分な場合、「公式ドキュメントの○○ページに詳細がある可能性があります」と案内

- **収録済み**: チュートリアル10ページ、リファレンス6ページ、マニュアル17ページ、拡張プラグイン7ページ、TextMeshPro10ページ、サンプル3ページ、Unity一般7ページ、事例3ページ、Q&A/DL3ページ
