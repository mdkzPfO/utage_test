# UTAGE シナリオ基本スキル

## 概要

宴(UTAGE)シナリオの基本的な記述を支援するスキル。テキスト表示、キャラクター表示、背景、サウンドの制御をカバーする。

## いつ使うか

以下の話題が出たとき:
- テキスト・セリフの表示方法
- キャラクター立ち絵の表示・切替・非表示
- 背景・イベントCG の表示
- BGM・SE・ボイス・環境音の再生・停止
- PageCtrl によるページ制御
- エクセルシナリオの基本的な書き方

## 前提知識

宴のシナリオはExcelファイルで記述する。基本構造:
- **Command列**: コマンド名（空欄ならテキスト表示）
- **Arg1〜Arg6列**: コマンド引数
- **Text列**: 表示テキスト
- **PageCtrl列**: ページ制御
- **Voice列**: ボイスファイル名

## コマンドリファレンス

### テキスト表示

Command/Arg1を空欄にし、Text列にテキストを書くと表示される。

| PageCtrl | 動作 |
|----------|------|
| 空欄 | 改ページ入力待ち |
| Input | 入力待ち後、次コマンド実行 |
| InputBr | 改行入力待ち |
| Next | 入力待ちなしで次コマンド実行 |
| Br | 自動改行して次コマンド実行 |
| BrPage | 自動改ページして次コマンド実行 |

テキスト内で使えるタグ: `<color=red>赤字</color>`, `<size=40>大きい</size>`, `<param=変数名>`

### セリフ・キャラクター表示

| 項目 | 内容 |
|------|------|
| Command | 空欄 |
| Arg1 | キャラクター名（必須） |
| Arg2 | 表情パターン名（省略時は前回を維持） |
| Arg3 | レイヤー名 |
| Arg4 | X座標 |
| Arg5 | Y座標 |
| Arg6 | フェード秒数（デフォルト0.2） |
| Text | セリフテキスト |
| Voice | ボイスファイル名 |

**例: キャラ表示 + セリフ**
| Command | Arg1 | Arg2 | Arg3 | Text |
|---------|------|------|------|------|
| | Haruka | smile | Left | こんにちは！ |

**立ち絵なしでセリフだけ**: Arg2に`<Off>`を指定

### キャラクター非表示 (CharacterOff)

| Arg1 | Arg2 |
|------|------|
| キャラ名（空欄で全員） | フェード秒数（デフォルト0.2） |

### 背景表示 (Bg / BgOff)

| Command | Arg1 | Arg2 | Arg3 | Arg4 | Arg5 |
|---------|------|------|------|------|------|
| Bg | テクスチャラベル | レイヤー名 | X座標 | Y座標 | フェード秒数(0.2) |
| BgOff | フェード秒数(0.2) | | | | |

背景オブジェクト名は自動的に「BG」になる（Tweenターゲット時に使用）。

### イベントCG (BgEvent / BgEventOff)

| Command | Arg1 | Arg2 | Arg3 | Arg4 | Arg5 | Arg6 |
|---------|------|------|------|------|------|------|
| BgEvent | テクスチャラベル | イベントモードON/OFF（FALSE=立ち絵継続） | レイヤー名 | X | Y | フェード秒数 |
| BgEventOff | フェード秒数 | | | | | |

**注意**: BgEvent表示中はキャラ立ち絵が自動非表示。Bgコマンドで通常モードに復帰。

### サウンド系コマンド

| Command | Arg1 | Arg2 | Arg3 | Arg4 | Arg5 |
|---------|------|------|------|------|------|
| **Bgm** | BGMラベル | ループ(TRUE) | 音量(0〜1) | 前曲フェードアウト秒(0.2) | フェードイン秒(0) |
| **StopBgm** | フェード秒(0.2) | | | | |
| **Se** | SEラベル | ループ(FALSE) | 音量(0〜1) | | |
| **StopSe** | SEラベル(空で全停止) | フェード秒(0.2) | | | |
| **Ambience** | 環境音ラベル | ループ(FALSE) | 音量(0〜1) | フェードアウト秒(0.2) | フェードイン秒(0) |
| **StopAmbience** | フェード秒(0.2) | | | | |
| **Voice** | キャラクターラベル | ループ(FALSE) | 音量(0〜1) | ボイスファイル名 | |
| **StopSound** | 種類(Bgm,Se,Ambience,Voice,All) | フェード秒(0.2) | | | |
| **ChangeSoundVolume** | 種類 | 音量(0〜1) | フェード秒(0) | | |

**ボイス再生**: 通常はセリフ行のVoice列にファイル名を指定。Voiceコマンドはセリフとは別にボイスを鳴らす場合に使用。

## 設定シート

| シート名 | 用途 |
|---------|------|
| Character | キャラクター名・表情パターン・テクスチャ対応 |
| Texture | 背景・イベントCG・スプライトのテクスチャ設定 |
| Sound | BGM・SE・環境音のラベル・ファイル対応 |
| Layer | 表示レイヤーの名前・位置・描画順 |
| Param | ゲーム内パラメーター定義 |
